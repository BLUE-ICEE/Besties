# 🌌 Nebula Nook

A fun, static "universal hub" website for GitHub Pages.

## Included

- 🌠 Animated space background
- 🤖 NOVA browser-only chatbot (no API key)
- 🎮 Planet Picker
- ⚡ Reaction Rush
- 🔢 Cosmic Guess
- 🧠 Memory Orbit
- 🪐 Random space facts
- 🎲 Cosmic dice
- 🎨 Nebula generator
- 🔮 Future message generator
- 👽 Alien translator
- 🪪 Custom local space name
- 🌙 Light/dark vibe toggle
- 📱 Responsive layout

## Run locally

Just open `index.html` in a browser.

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. In **Settings → Pages**, choose the branch containing these files and the root folder.
4. Save. GitHub will publish the site.

Everything here is client-side, so there is no server or database required.

## Customize

The easiest place to start is `script.js`:
- Add more entries to the `facts` array.
- Add more `missions`.
- Add NOVA responses.
- Add games and widgets.

The CSS variables at the top of `style.css` control the main colors.
